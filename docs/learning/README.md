Python

# Week 2 — Database

Add PostgreSQL.

Practise:

schema design
relationships
indexes
transactions
migrations
SQL queries

And importantly, practise explaining why you chose a particular design.

# Week 3 — Production thinking

Take your little application and add:

Docker
CI/CD
authentication
configuration/secrets
structured logging
health checks
basic observability

Now you're thinking like a Technical Lead rather than simply writing code.

# Week 4 — AI/RAG

Given CyINTer's domain, build a tiny RAG application.

Something simple:

Documents
↓
Chunking
↓
Embeddings
↓
Vector store
↓
Retriever
↓
LLM
↓
Grounded answer

Then deliberately ask:

How do I evaluate retrieval?
What happens when retrieval fails?
How do I prevent hallucination?
How do I track provenance?
What happens when the LLM is unavailable?
What does this cost at scale?
