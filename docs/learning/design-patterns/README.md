# Software Design Patterns

What are design patterns?  
They are common blueprints that can be adopted for solve a particular design problem in a codebase.

Why do we use them (Benefits) ?

- They are widely used solutions which are tried and tested to address software design problems.
- Enables easier communication with the team as they promoote a common language

The main distinctions are:

- Creational
- Structural
- Behavioural
